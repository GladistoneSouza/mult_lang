# Francês — Curso atual

Esta pasta registra **somente o conteúdo que já foi estudado na prática**.

O material mais avançado existente no repositório permanece separado e não deve ser tratado como conteúdo já aprendido.

## Objetivo

Construir o estudo de francês progressivamente, usando:

- vocabulário já visto;
- frases curtas e palavras fáceis;
- exemplos do cotidiano;
- exercícios de tradução e compreensão;
- revisão cumulativa;
- notas simples de pronúncia quando forem úteis.

## Regra de progressão

Uma palavra ou estrutura nova só entra nesta área depois de aparecer nas lições/práticas atuais. Exemplos podem combinar palavras já conhecidas, evitando introduzir gramática avançada sem necessidade.
